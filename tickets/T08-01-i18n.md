**Status:** TODO

## Objective

Separate all visible product strings from components and support English plus at least Hindi.

## Scope of work

Add locale dictionaries, language picker, number/date formatting and untranslated-string detection. Preserve source text for extracted/legal content; show its original language. Do not machine-translate a rule citation into the official source itself. Marathi can be added if reviewed translations are available.

## Acceptance criteria

[ ] Core navigation, forms, errors and statuses use dictionaries.
[ ] English and Hindi cover all core flows.
[ ] No hardcoded English labels in shared components.
[ ] Locale change does not alter underlying values or evaluation.
[ ] Accessible language names and direction handling are tested.

## Required tests / evidence

Dictionary key coverage; locale persistence; keyboard picker; date formatting tests.
